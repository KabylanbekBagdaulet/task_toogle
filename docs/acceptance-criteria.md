# Acceptance criteria

1. A visitor can add a non-empty task title of up to 80 characters.
2. A visitor can mark a task complete and restore it to active.
3. All, active, and completed filters show the correct subset without changing task data.
4. A visitor can remove a task and receives a useful empty-state message when no matching tasks remain.
5. User-entered task titles render as text, not executable markup; no credentials or personal data are collected.
